# 🚀 AI-Powered Data Quality Monitoring System Using Databricks

## 📌 Project Overview

This project is an enterprise-grade data quality monitoring platform built using Databricks, Delta Lake, and Unity Catalog.

The system performs:
- Data ingestion
- Data cleaning
- Anomaly detection
- Automated email alerts
- Interactive dashboards
- Enterprise ETL workflows

---

## 🛠️ Technologies Used

- Databricks
- PySpark
- Delta Lake
- Unity Catalog
- SQL
- Python
- SMTP Email Alerts
